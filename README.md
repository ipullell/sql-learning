# SQL Learning Journey 🚀

This repository documents my journey of learning SQL from the fundamentals to more advanced concepts using PostgreSQL.

The goal of this repository is not only to learn SQL syntax, but also to develop the ability to solve real-world data problems through practice, exercises, and challenges.

---

## 🎯 Why This Repository Exists

As someone learning Data Engineering, SQL is one of the most important skills to master.

This repository serves as:

- A structured SQL learning roadmap
- A collection of practice queries
- A place to experiment with datasets
- A personal reference for future projects

---

## 🛠️ Environment

### Database
- PostgreSQL

### SQL Client
- DBeaver

### Dataset Sources
Datasets used throughout this repository may come from:

- Kaggle
- Public datasets
- Synthetic datasets
- Practice datasets created for learning

All datasets are stored inside the `data/` directory.
